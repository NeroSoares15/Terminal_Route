## Generated/Internal Assets

- Menu, cockpit, and ending artwork were generated for this prototype and imported under `Assets/Resources/TerminalRoute/Art`.
- Runtime audio is synthesized in code by `TerminalRouteAudio`; no external audio clips are currently required.
- Most gameplay-safe geometry is generated at runtime from Unity primitives to avoid broken prefab scale/pivot issues close to delivery.

## Before Submission
