## Generated/Internal Assets

- Menu, cockpit, ending artwork, logo artwork, and the scary 2D monkey artwork were generated for this prototype and imported under `Assets/Resources/TerminalRoute/Art`.
- Runtime audio uses imported project clips when present, with synthesized fallback tones/noise in `TerminalRouteAudio`.
- Current imported audio clips:
  - `Main Menu.mp3`
  - `gameplay.mp3`
  - `Intro voicemail phone.wav`
  - `freesound_community-bus-interior-22321.mp3`
  - `freesound_community-inside-bus-67286.mp3`
- Confirm author/source/license details for the imported audio clips before final public submission, especially the two Freesound community clips.
- Most gameplay-safe geometry is generated at runtime from Unity primitives to avoid broken prefab scale/pivot issues close to delivery.
